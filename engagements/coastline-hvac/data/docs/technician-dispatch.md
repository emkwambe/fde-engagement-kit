# Technician Dispatch Rules

Owner: Dispatch Operations.

## Dispatch Rules
1. Emergencies after hours go to the on-call technician only.
2. The technician's skill must match the equipment: residential, commercial, or refrigeration.
3. The dispatch reason must name the work order, its priority, and the after-hours fee if one applies.
4. The after-hours fee follows after-hours-fees.md and is never above $150.

## Double Booking
A technician with an open dispatch is not sent to a second emergency until the first is closed, unless the
dispatch operations manager agrees.

# Carrier Escalation Guide

Owner: Transportation

## When to Escalate
Escalate when a shipment shows no scan for 48 hours, when the status is "Delayed" for more than 24 hours, or when a Platinum order is at risk.

## Contacts
Use the carrier portal first. For Platinum orders, call the carrier's priority desk listed in the ERP carrier record.

## Notes Field
Record every escalation in the shipment notes so the next agent sees the history.
